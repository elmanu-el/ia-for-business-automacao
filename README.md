# IA for Business — Diferenciais da automação com IA

Repositório de entregas da aula "Diferenciais da automação com IA" (módulo AI Automation).

## O que você entrega

Uma tabela com **5 tarefas** de um processo real, respondendo às três perguntas para cada tarefa:

1. **Quem é pago para fazer isso hoje?**
2. **Quanto custa por unidade, e quantas vezes acontece por mês?**
3. **Quanto custa um erro?**

Depois, decida para cada tarefa entre **regra, IA ou humano**, e justifique em uma frase.

Use o modelo em [`TEMPLATE.md`](TEMPLATE.md). Veja um exemplo preenchido em [`entregas/exemplo-varejo/tarefas.md`](entregas/exemplo-varejo/tarefas.md).

## Como entregar (sem precisar saber Git)

1. Abra a pasta [`entregas`](entregas) aqui no GitHub.
2. Clique em **Add file → Create new file**.
3. No nome do arquivo, digite `nome-do-seu-time/tarefas.md` (a barra cria a pasta do time).
4. Cole o conteúdo do `TEMPLATE.md` e preencha.
5. Clique em **Commit changes** e depois em **Propose changes**. O GitHub cria uma cópia (fork) e abre um Pull Request.
6. Na descrição do Pull Request, responda à **pergunta de saída** (o modelo já aparece lá).

Cada time mantém a sua pasta. A tarefa que vocês marcarem como **IA** é o ponto de partida da entrega de automação do semestre.
